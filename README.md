# Real-time-object-detection
detects objects in image ,video and webcam.

**#Project Overview**
Real-Time Object Detection Using Deep Learning is a web-based application that detects and identifies multiple objects from images, videos, and live webcam streams.
The system uses the YOLO deep learning model to detect objects and display their locations using bounding boxes with object labels.
**Objectives**
Detect objects in real time.
Identify multiple objects in images and videos.
Display detected objects using bounding boxes.
Perform live object detection using a webcam.
Build a simple and user-friendly web interface.
**Technologies Used**
**Backend:**
Python
Flask
YOLOv8
OpenCV
**Frontend:**
HTML5
CSS3
JavaScript
Dataset:
COCO Dataset

**Features**
Image-based object detection
Video-based object detection
Real-time webcam detection
Multiple object detection
Bounding box visualization
Object identification and confidence scores
